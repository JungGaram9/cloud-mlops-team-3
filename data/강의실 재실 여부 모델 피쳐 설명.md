# 실내 재실 예측 모델 피쳐 설명

- 원본 데이터: `training_dataset.csv` 8,143행 / `test_dataset.csv` 12,417행. 아래 통계는 두 파일을 합쳐 분석한 기존 피처 선정 기록입니다.
- 전체 행/열: 20,560행 × 8열 (시간 파생변수 포함)
- 결측치: 없음

## 현재 학습·테스트 입력

v1·v2 구현은 센서 4개만 학습했습니다. **v3부터 이 문서의 6개 피처를 모두 학습·추론에 사용합니다.** `Hour`와 `DayOfWeek`는 원본 CSV의 `date`에서 추출하며 웹·Swagger에서는 사용자가 직접 입력합니다. 요일 번호는 월요일 0~일요일 6입니다.

시간과 요일은 주기형 sin/cos로 변환하고 요일에서 주말 여부를 함께 계산합니다. 조도 포함 신경망 입력은 9개, 조도 제외는 8개입니다. 학습과 단건 추론은 `models/model.py`의 같은 변환을 사용합니다. 학습·검증은 학습 CSV 안에서 시간순으로 분리하며 평가 CSV는 학습에 사용하지 않습니다.

v3의 별도 평가 정확도는 조도 포함 98.96%, 제외 85.17%입니다. 세부 결과와 한계는 루트 README와 `models/reports/v3/`에 기록합니다.

|---|---|---|
| **Occupancy** | 실제 재실 여부 (0: 비어있음, 1: 사람있음) | 0 (비어있음) 15,810건 (76.9%) / 1 (사람있음) 4,750건 (23.1%) — 클래스 불균형 존재 |

## 선정 피쳐 (Features)

| 피쳐 | 타입 | 선정 근거 |
|---|---|---|
| **Light** | 수치형 | Occupancy와 상관계수 **0.915**로 전체 피쳐 중 가장 강한 연관성. 조도가 높을수록(불을 켤수록) 재실 가능성 급증 |
| **Temperature** | 수치형 | 상관계수 **0.556**. 실내 온도가 높아질수록 재실 가능성 상승 (양의 상관) |
| **CO2** | 수치형 | 상관계수 **0.502**. 이산화탄소 농도가 높을수록 재실 의도 증가 (사람의 호흡에 의한 수치 증가 반영) |
| **Humidity** | 수치형 | 상관계수 **0.046**. 타 변수에 비해 상관성은 낮으나, 복합적인 실내 환경 상태를 파악하는 보조 변수 역할 |
| **Hour** | 범주형 | 측정 시간대에 따라 재실율 편차가 매우 큼 (16시 70.3% ↔ 새벽 0%), 일과 및 활동 시간대 패턴 반영 |
| **DayOfWeek** | 범주형 | 요일별 재실율 차이 뚜렷하게 존재 (평일 최대 37.5% ↔ 토, 일요일 0.0%), 주말과 평일의 건물 사용 패턴 반영 |
