## 오탐·재실 누락과 미해결 문제

- 실제 test: 빈방 오탐 574 → 515건, 재실 누락 236 → 237건.
- 합성 빈방 점등 128건 중 오탐 60 → 88건.
- 합성 재실 305건 중 누락 233 → 194건.
- 합성 어두운 재실 47건 중 누락 47 → 47건.

전체 정확도 상승과 상황별 악화는 함께 판단해야 합니다. 이 실험은 모델 승격을 수행하지 않으며, 해결되지 않은 재실 누락이나 빈방 점등 오탐을 성공으로 간주하지 않습니다.

## 해석 범위

지도학습 재학습이며 강화학습 테스트는 미실행입니다. 행동·보상·정책 갱신이 구현되어 있지 않습니다.
합성 heldout은 동일 생성 프로필의 별도 방/사건이며 희귀 사건을 우선 포함한 개발 표본입니다. 실제 강의실 성능이나 자연 발생 비율의 성능을 보장하지 않습니다.
실제 test는 시간적으로 학습 이전·이후가 혼재한 기존 고정 CSV이므로 순수 미래 성능도 아닙니다.
기본 모델 포인터는 변경하지 않았습니다. 재시도·추가 튜닝 없이 결과를 보존합니다.

유형별·빈방 점등·재실 누락 지표와 provenance는 experiment.json 및 synthetic_comparison.json, 버전별 training.json에 기록합니다.


## 재현성·로그 진단

동일 조건의 재현 검증에서 기준·후보 가중치·표준화 통계·학습 이력이 원본과 비트 단위로 일치했습니다(`reproducibility-fixed.json`). 최초 검증은 원래 열 선택에 따른 입력 메모리 배치를 생략해 실패했으며 결과도 `reproducibility.json`에 보존했습니다. 비교 학습 2회, 검증 학습 4회(최초 실패 2회+수정 검증 2회), 총 6회이며 성능 튜닝은 0회입니다. 검증 학습에서 실제 test 지표를 계산하지 않았습니다.

로컬 시연은 5,841행 중 예측 828행 모두 정답 없는 model_prediction이므로 학습 후보 0행입니다. 합성 실험은 training 404행과 pipeline_observation 5,000행을 독립 생성물과 대조했고 train 관측 1,000행 중 600행을 사용했습니다. 운영 EC2 로그는 SSH 연결 시간 초과로 수집하지 못했으며 이 두 로그 출처와 구분합니다.

합성 주요 오판 175건씩을 같은 모델로 재추론해 저장 결과와 일치함을 확인했습니다. 실제 fit의 어두운 재실은 180행, 피드백에는 4행이었습니다. 어두운 재실 47건의 조도만 450으로 바꾼 감도 진단에서는 두 모델 모두 37건을 재실로 바꿔 판정했습니다. 이 변형 입력은 실제 관측이나 새 정답·학습 데이터·성능 개선으로 사용하지 않았습니다. 현재 회귀를 데이터 연결 오류나 평가 집계 오류로 해소할 근거는 없으며 후보를 승격하지 않았습니다.

운영 모델과의 비교, 실제 재배포, 배포 후 개선 확인 및 화면 캡처는 수행하지 않았습니다. summary.json에는 지표·학습 조건·해시·유형별 결과만 포함하며 원시 CSV·로그·SQLite·가중치 바이너리는 공유 대상에서 제외합니다.
